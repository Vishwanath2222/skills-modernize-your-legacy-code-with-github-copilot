## Notes for stakeholder validation

- The current implementation maintains a single in-memory balance initialized to `1000.00`.
- Balance updates are persisted for the duration of the running process.
- Invalid inputs outside the menu range are rejected without altering the balance.
- Transactions are based on the account state available at the time of each operation.
- This test plan should be executed and completed with the actual results during stakeholder review before converting the logic to the Node.js application.
